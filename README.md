#### 1. 📈 [NexaPlan](https://github.com/taoako/NexaPlan) — *Enterprise Planning & Machine Learning Forecasting*
- **Overview:** A full-stack, multi-role web application paired with a custom machine learning forecasting engine designed to turn historical data into actionable projections.
- **Engineering Highlights:** Built with a TypeScript/C# application layer, a Python-powered ML forecasting microservice, and MySQL persistence, deployed across cloud environments (`Vercel` & `Render`).

#### 2. 🤖 Age-Adaptive Self-Service QSR Kiosk — *Computer Vision & Data Mining Capstone*
- **Overview:** An intelligent Quick-Service Restaurant (QSR) tablet kiosk that dynamically adapts its UI/UX accessibility based on customer age estimation and recommends high-affinity menu bundles.
- **Engineering Highlights:** Combines **InsightFace** for real-time demographic detection with the **Apriori algorithm** for market-basket association rule mining.

#### 3. 📱 [QR-Ordering-System-POS-Integrated](https://github.com/Ordn1/QR-Ordering-System-POS-Integrated_Shaxian) — *Hospitality Tech*
- **Overview:** Streamlines restaurant operations by linking customer table QR code ordering directly into a unified kitchen and cashier Point-of-Sale dashboard.
- **Engineering Highlights:** Responsive `React` frontend coupled with a `Python` backend for real-time order state synchronization.

#### 4. 🍲 [Recipe App](https://github.com/faithangel3003/recipe_app) — *Cross-Platform Mobile & Web*
- **Overview:** A clean, intuitive application for browsing, saving, and categorizing recipes with step-by-step preparation flows.
- **Engineering Highlights:** Built using `Dart` and `HTML` with a focus on smooth cross-device UI performance.
